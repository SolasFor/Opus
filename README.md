# Opus

Три интерактивные 3D-сцены на **Three.js** — без сборки, без npm, без локальных ассетов. Солнечная система — один самодостаточный HTML-файл. Аквариум и Двигатель — модульные версии (`Akvarium/index.html`, `Engine/index.html` и ES-модули в `src/`) и однофайловые `Akvarium/Aquarium.html` и `Engine/Engine.html`. Вся геометрия, текстуры и звук генерируются процедурно прямо в браузере.

**▶ Онлайн-демо: <https://solasfor.github.io/Opus/>**

| Демо | Что внутри | Онлайн | Файл |
|------|-----------|--------|------|
| 🐠 **Аквариум** | Рифовая сцена: стаи рыб, свет, вода, каустика | [открыть](https://solasfor.github.io/Opus/Akvarium/) | [`Akvarium/index.html`](Akvarium/index.html), однофайловая — [`Akvarium/Aquarium.html`](Akvarium/Aquarium.html) |
| ⚙️ **Двигатель** | Рядная «четвёрка» DOHC 16V: разборка, разрез, рабочий цикл | [открыть](https://solasfor.github.io/Opus/Engine/) | [`Engine/index.html`](Engine/index.html), однофайловая — [`Engine/Engine.html`](Engine/Engine.html) |

> Интерфейс обеих сцен — на русском языке.

## Запуск

Солнечную систему и однофайловые версии аквариума (`Akvarium/Aquarium.html`) и двигателя (`Engine/Engine.html`) можно открыть в браузере двойным щелчком. Модульным версиям (`Akvarium/index.html`, `Engine/index.html`) нужен веб-сервер, например локальный:

```bash
python -m http.server 8000
```

После этого:

- Аквариум — <http://localhost:8000/Akvarium/> (однофайловая версия — <http://localhost:8000/Akvarium/Aquarium.html>)
- Двигатель — <http://localhost:8000/Engine/> (однофайловая версия — <http://localhost:8000/Engine/Engine.html>)
- Солнечная система — <http://localhost:8000/SolarSystem/SolarSystem.html>

**Требования:** современный браузер с WebGL и ES-модулями, доступ в интернет. Three.js подгружается с CDN: в Аквариуме и Двигателе — версия 0.160 с аддонами через `importmap` (unpkg), в Солнечной системе — r128 (cdnjs и unpkg).

## 🐠 Аквариум

Живая рифовая сцена с настраиваемым светом, водой и поведением рыб.

**Что есть**

- **Рыбы шести видов:** зелёный хромис и золотистый антиас (большие стаи), рыба-клоун, голубой и жёлтый хирурги, мавританский идол. Стаи ведут себя по правилам сближения, выравнивания и расталкивания; у каждого вида свои пропорции, скорость и амплитуда хвоста.
- **Свет:** пресеты «День», «Закат», «Ночь» с плавным переходом, плюс ручной слайдер ночи.
- **Вода:** течение, мутность, скорость времени, количество рыб — всё слайдерами.
- **Каустика** встроена в материалы, поэтому световой рисунок ложится по рельефу дна, а не висит плоско.
- **Сцена:** песок, камни, водоросли, актинии, веерные кораллы, аэратор с пузырьками.
- **Режимы:** автокамера, свободная камера, вид от лица рыбы, фонарик у курсора, «рыбы боятся курсора», звук.
- **Кнопки:** «Покормить», «Стук», «Снимок» (сохраняет PNG).

**Управление**

| Действие | Как |
|----------|-----|
| Корм | клик; зажать — сыпать непрерывно |
| Следить за рыбой | двойной клик по рыбе |
| Стук по стеклу | правая кнопка мыши |
| Камера | тянуть — вращать, колесо — зум |

| Клавиша | Действие |
|---------|----------|
| `1` `2` `3` | День / Закат / Ночь |
| `C` | Камера от лица рыбы |
| `F` | Покормить |
| `K` | Стук |
| `Space` | Пауза |
| `H` | Скрыть / показать панель |

## ⚙️ Двигатель

Четырёхтактный рядный четырёхцилиндровый двигатель (DOHC, 16 клапанов, порядок работы **1-3-4-2**) с полной интерактивной разборкой.

**Что есть**

- **Разборка:** общий слайдер, кнопки «Собрать» / «Разобрать полностью» и пошаговый режим «◀ Назад / Далее ▶».
- **Режимы вида:** сплошной, рентген, разрез — с выбором положения плоскости (по осям цилиндров и т. д.).
- **Рабочий цикл:** кривошипно-шатунный механизм, кулачки и клапаны, ремень ГРМ; свечение камер, искра, вспышка, частицы смеси и выхлопа по тактам.
- **Управление циклом:** запуск/пауза, замедление, скорость, угол коленвала с шагом ±5°.
- **Диаграммы:** порядок работы по цилиндрам (впуск, сжатие, рабочий ход, выпуск) и p–V диаграмма выбранного цилиндра.
- **Карточки деталей:** клик по детали открывает описание; можно приблизить, изолировать, показать подписи.
- **Камера:** пресеты (спереди, сбоку, сверху, изометрия), автовращение, снимок в PNG, синтезированный звук (WebAudio).
- **Телефон:** нижняя шторка с вкладками и тремя высотами, в альбомной ориентации — шторка справа; учтены безопасные зоны экрана.

**Управление**

Мышь: тянуть — вращать, колесо — зум, правая кнопка — сдвиг. Клик по детали — карточка, двойной клик — изолировать.

Сенсорный экран: один палец — вращать, два — зум и сдвиг, касание детали — карточка, двойное касание — изолировать. На телефоне (ширина меньше 760 px) панели собраны в нижнюю шторку: в свёрнутом виде видны запуск и пауза, угол цикла и порядок работы 1–3–4–2, а вкладки «Работа», «Разборка», «Вид» и «Детали» открывают её на половину экрана. Ручку шторки можно потянуть или коснуться её — три высоты. В альбомной ориентации (высота меньше 500 px) шторка стоит справа, её скрывает кнопка на плашке слева вверху или клавиша `H`.

| Клавиша | Действие |
|---------|----------|
| `Space` | Запуск / пауза |
| `S` | Замедление ×0,2 |
| `,` `.` | Коленвал −5° / +5° (`Shift` — 1°) |
| `+` `−` | Быстрее / медленнее |
| `←` `→` | Шаги разборки |
| `E` | Разобрать / собрать |
| `X` | Вид: сплошной → рентген → разрез |
| `L` | Подписи деталей |
| `1`–`4` | Камера: спереди, сбоку, сверху, изометрия |
| `R` | Сбросить камеру |
| `A` | Автовращение |
| `M` | Звук |
| `F` | Приблизить выбранную деталь |
| `I` | Изолировать выбранную |
| `P` | Снимок PNG |
| `H` | Скрыть / показать панели |
| `Esc` | Закрыть карточку / выйти из изоляции |
| `?` | Список горячих клавиш |

Сцену можно вращать и без мыши: `Tab` переводит фокус на сцену (вокруг неё появляется рамка), дальше —

| Клавиша | Действие |
|---------|----------|
| `←` `→` `↑` `↓` | Вращать камеру (шаг 5°) |
| `Shift` + стрелки | Сдвинуть камеру |
| `PgUp` `PgDn` | Приблизить / отдалить |

Все кнопки, ползунки и меню доступны с `Tab`; в меню камеры — стрелки, `Home`, `End`, `Esc`. `Space` и `Enter` на кнопке или ползунке нажимают сам элемент и не запускают двигатель; на ползунке стрелки меняют его значение, а не шаг разборки.

Если в системе включено «Уменьшение движения» (`prefers-reduced-motion`), камера и разборка не летят дольше 0,15 с, стартовый облёт и вспышка снимка отключены. Числа выводятся в русском формате (`×1,0`, `0,92 бар`). Параметр `?debug` в адресе (`Engine/index.html?debug`) показывает счётчик кадров.

## 🪐 Солнечная система

Интерактивная экспедиция по Солнечной системе в стиле «орбитального архива».

**Что есть**

- **Солнце и восемь планет** на орбитах с видимыми линиями траекторий. Периоды обращения и скорости вращения пропорциональны реальным, расстояния и размеры подобраны для наглядности. У Сатурна есть кольца.
- **Карточка планеты:** тип, диаметр, орбитальный период, расстояние от Солнца, число спутников и блок «Знаете ли вы?».
- **Навигация:** клик по планете наводит на неё камеру и открывает карточку; при наведении планета слегка увеличивается.
- **Время:** кнопка паузы и слайдер скорости симуляции.
- **Камера:** свободное вращение мышью, кнопка «↺ Сбросить вид».
- Фон из звёзд, свечение Солнца и текстуры планет генерируются процедурно.

**Управление**

| Действие | Как |
|----------|-----|
| Камера | тянуть — вращать, колесо — зум, правая кнопка — сдвиг |
| Выбрать планету | клик по ней |
| Закрыть карточку | кнопка `×` |
| Пауза | кнопка «Пауза» |
| Скорость | слайдер «Скорость» |
| Вернуть вид | «↺ Сбросить вид» |

## Публикация на GitHub Pages

Репозиторий готов к Pages без сборки: в **Settings → Pages → Build and deployment** выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`. Через минуту-две сайт появится на <https://solasfor.github.io/Opus/>.

## Технические заметки

- Солнечная система — один файл, весь код внутри HTML.
- Аквариум: `Akvarium/index.html` подключает `Akvarium/styles/app.css` и `Akvarium/src/main.js`, который импортирует `core.js` (renderer, камера, свет, ГПСЧ, общий GLSL), `scenery.js` (декорации) и `creatures.js` (рыбы, пузыри, медузы). Модульная версия перенесена из однофайловой механически (D-13, правила — `Akvarium/tests/split.test.js`) и дальше меняется одна; однофайловая `Akvarium/Aquarium.html` заморожена и сохранена для запуска без сервера.
- Двигатель: `Engine/index.html` подключает `Engine/src/main.js`, модель двигателя (спецификация, кинематика, цикл, газораспределение, давление) вынесена в модули `src/config` и `src/sim`. Однофайловая `Engine/Engine.html` сохранена для запуска без сервера.
- Аквариум и Двигатель: Three.js 0.160, ES-модуль и `importmap` (unpkg).
- Солнечная система: Three.js r128 и `OrbitControls` обычными `<script>` с CDN.
- Бандлер нигде не нужен.
- Тесты модели двигателя: `node --test Engine/tests/*.test.js` (Node 20.19+ или 22.7+, без зависимостей).
- Тесты аквариума (экран запуска, адаптивное разрешение, тестовые хуки, заморозка однофайловой версии): `node --test Akvarium/tests/*.test.js`. Параметр `?noadapt` в адресе аквариума отключает адаптивное разрешение.
- Геометрия — процедурная (объединённые меши и `InstancedMesh`), текстуры и шейдерные эффекты — в рантайме.
- Звук синтезируется через WebAudio и по умолчанию выключен.
