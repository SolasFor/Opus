# Opus

Три интерактивные 3D-сцены в браузере — без сборки, без npm, без локальных ассетов. Аквариум (чистый WebGL 2) и Солнечная система (Three.js r128) — самодостаточные HTML-файлы; Двигатель V12 60° (Three.js 0.160) — модульная версия (`Engine/index.html` и ES-модули в `Engine/src/`). Вся геометрия, текстуры и звук генерируются процедурно прямо в браузере.

**▶ Онлайн-демо: <https://solasfor.github.io/Opus/>**

| ⚙️ **Двигатель** | Атмосферный V12 60° (5,5 л, Quad-Cam DOHC 48V): разборка 11 узлов, поперечный разрез, цикл 12 цилиндров | [открыть](https://solasfor.github.io/Opus/Engine/) | [`Engine/index.html`](Engine/index.html) |

> Интерфейс всех сцен — на русском языке.

## Запуск

Аквариум (`Akvarium/Аквариум max.html`) и Солнечную систему (`SolarSystem/SolarSystem.html`) можно открыть в браузере двойным щелчком. Модульной версии двигателя V12 (`Engine/index.html`) нужен веб-сервер, например локальный:

```bash
python -m http.server 8000
```

После этого:

- Аквариум — <http://localhost:8000/Akvarium/%D0%90%D0%BA%D0%B2%D0%B0%D1%80%D0%B8%D1%83%D0%BC%20max.html>
- Двигатель — <http://localhost:8000/Engine/>
- Солнечная система — <http://localhost:8000/SolarSystem/SolarSystem.html>

**Требования:** современный браузер с WebGL 2 и ES-модулями. Для Двигателя (Three.js 0.160 с аддонами через `importmap` с unpkg) и Солнечной системы (Three.js r128 с cdnjs и unpkg) нужен доступ в интернет; Аквариум работает полностью автономно на чистом WebGL 2 без внешних библиотек.

## 🐠 Аквариум

Пресноводный растительный аквариум на собственном движке WebGL 2 в одном HTML-файле.

**Что есть**

- **Рыбы семи видов:** красный неон и клинопятнистая расбора (стайные), скалярия, петушок (халфмун), гуппи, лялиус, коридорас панда (донные). Процедурная геометрия тела, глаз и плавников, шейдер черепитчатой чешуи, волновой изгиб при плавании.
- **Сцена и вода:** рельефный песок, инстансированная галька, камни, колышущиеся водные растения, аэратор с пузырьками и взвесью, стеклянный резервуар с отражением комнаты и водной поверхностью, процедурная каустика (FBO) и карта теней.
- **Свет:** плавный переход между дневным светом и ночной подсветкой (кнопка «Ночь»).
- **Интерактивность и камера:** кормление кликом/касанием по воде или кнопкой «Покормить»; режим «Следить» (последовательно переключает камеру по всем семи видам рыб); кнопка сброса вида («↺»); плавное покачивание камеры при простое.
- **Производительность и доступность:** автоснижение разрешения и сглаживания на медленных кадрах (хеш `#hq` в адресе отключает автоснижение), пауза при скрытии вкладки, обработка потери WebGL-контекста, поддержка `prefers-reduced-motion` и `aria-live`.

**Управление**

| Действие | Мышь | Касание |
|----------|------|---------|
| Вращать камеру | тянуть (ЛКМ) | один палец |
| Сдвиг | ПКМ / СКМ / `Shift + тянуть` | два пальца |
| Зум | колесо (к курсору) | щипок двумя пальцами |
| Покормить в точке | клик по воде | касание по воде |

Нижняя панель: **«Покормить»**, **«Ночь»**, **«Следить»**, **«Сбросить вид» (`↺`)**.

Клавиатура (при фокусе на холсте через `Tab`):

| Клавиша | Действие |
|---------|----------|
| `←` `→` `↑` `↓` | Вращать камеру |
| `+` / `−` | Приблизить / отдалить |
| `0` / `Home` | Сбросить вид |

## ⚙️ Двигатель

Атмосферный V-образный 12-цилиндровый двигатель с углом развала 60° (5,5 л, 88 × 75 мм, сжатие 11,5 : 1, Quad-Cam DOHC, 48 клапанов, порядок работы **1-7-5-11-3-9-6-12-2-8-4-10**) с полной интерактивной разборкой на 11 узлов и фотореалистичными PBR-материалами.

**Что есть**

- **Разборка:** общий слайдер, кнопки «Собрать» / «Разобрать полностью» и пошаговый режим «◀ Назад / Далее ▶» (10 шагов, 11 узлов).
- **Режимы вида:** сплошной, рентген, поперечный разрез — с выбором положения плоскости (по парам цилиндров, с шагом по продольной оси).
- **Графика и рабочий цикл:** студийный свет и PMREM-окружение, карбон 2×2 twill, гильзы Nikasil с плато-хонингованием 45°, красная шагрень клапанных крышек, Inconel-коллекторы с тепловым свечением, GTAO + HDR-блум; КШМ на 6 общих шейках, 4 распредвала и 48 клапанов, два ремня, свечение 12 камер и частицы смеси.
- **Управление циклом:** запуск/пауза, замедление, скорость, угол коленвала с шагом ±5°, синтез звука V12.
- **Диаграммы:** порядок работы 12 цилиндров с интервалом 60° (впуск, сжатие, рабочий ход, выпуск) и p–V диаграмма выбранного цилиндра.
- **Карточки деталей:** клик по детали открывает описание; можно приблизить, изолировать, показать подписи.
- **Камера:** пресеты (спереди, сбоку, сверху, изометрия), автовращение, снимок в PNG, синтезированный звук (WebAudio).
- **Телефон:** нижняя шторка с вкладками и тремя высотами, в альбомной ориентации — шторка справа; учтены безопасные зоны экрана.

**Управление**

Мышь: тянуть — вращать, колесо — зум, правая кнопка — сдвиг. Клик по детали — карточка, двойной клик — изолировать.

Сенсорный экран: один палец — вращать, два — зум и сдвиг, касание детали — карточка, двойное касание — изолировать. На телефоне (ширина меньше 760 px) панели собраны в нижнюю шторку: в свёрнутом виде видны запуск и пауза, угол цикла и порядок работы 1–3–4–2, а вкладки «Работа», «Разборка», «Вид» и «Детали» открывают её на половину экрана. Ручку шторки можно потянуть или коснуться её — три высоты. В альбомной ориентации (высота меньше 500 px) шторка стоит справа, её скрывает кнопка на плашке слева вверху или клавиша `H`.

| Клавиша | Действие |
|---------|----------|
| `Space` | Запуск / пауза |
| `S` | Замедление ×0,2 |
| `,` `.` | Коленвал −5° / +5° (`Shift` — 1°) |
| `+` `−` | Быстрее / медленнее |
| `←` `→` | Шаги разборки |
| `E` | Разобрать / собрать |
| `X` | Вид: сплошной → рентген → разрез |
| `L` | Подписи деталей |
| `1`–`4` | Камера: спереди, сбоку, сверху, изометрия |
| `R` | Сбросить камеру |
| `A` | Автовращение |
| `M` | Звук |
| `F` | Приблизить выбранную деталь |
| `I` | Изолировать выбранную |
| `P` | Снимок PNG |
| `H` | Скрыть / показать панели |
| `Esc` | Закрыть карточку / выйти из изоляции |
| `?` | Список горячих клавиш |

Сцену можно вращать и без мыши: `Tab` переводит фокус на сцену (вокруг неё появляется рамка), дальше —

| Клавиша | Действие |
|---------|----------|
| `←` `→` `↑` `↓` | Вращать камеру (шаг 5°) |
| `Shift` + стрелки | Сдвинуть камеру |
| `PgUp` `PgDn` | Приблизить / отдалить |

Все кнопки, ползунки и меню доступны с `Tab`; в меню камеры — стрелки, `Home`, `End`, `Esc`. `Space` и `Enter` на кнопке или ползунке нажимают сам элемент и не запускают двигатель; на ползунке стрелки меняют его значение, а не шаг разборки.

Если в системе включено «Уменьшение движения» (`prefers-reduced-motion`), камера и разборка не летят дольше 0,15 с, стартовый облёт и вспышка снимка отключены. Числа выводятся в русском формате (`×1,0`, `0,92 бар`). Параметр `?debug` в адресе (`Engine/index.html?debug`) показывает счётчик кадров.

## 🪐 Солнечная система

Интерактивная 3D-экспедиция по Солнечной системе в стиле «орбитального архива» на Three.js r128 с аналитическими тенями, выборочным HDR-bloom, эфемеридами J2000 и процедурным Web Audio эмбиентом.

**Что есть**

- **Солнце, 8 планет, Церера, Плутон–Харон, 10 спутников и комета 1P/Галлея:** наклонные 3D-эллиптические орбиты J2000 (включая ретроградную орбиту кометы и взаимный танец Плутона и Харона вокруг общего барицентра), два хвоста кометы (прямой ионный от Солнца и изогнутый пылевой по касательной) с комой, шлейфы Энцелада, дымка Титана, кольца Сатурна и Урана.
- **Атмосферы и сияния:** рэлеевское рассеяние на линии терминатора (`uSunset`), тёплые закаты на Земле/Венере и холодные на Марсе/Плутоне, полярные овалы сияний на Земле, Юпитере, Сатурне и Уране.
- **Машина времени J2000 и астрономические события:** выбор произвольной даты UTC, шаг времени (`1 дн/с` … `1 год/с`), кнопка «Сегодня» (`T`) и меню исторических событий (Великое соединение 21.12.2020, перигелии Галлея 1986 и 2061, пролёт New Horizons мимо Плутона 14.07.2015, запуск Voyager 1).
- **Сравнение размеров 1:1 (`G`) и Истинный 1:1 (`R`):** плавная перестройка всех тел в линейку пропорциональных диаметров у края Солнца (`⇄ Сравнить`), либо переключение всей системы в масштаб `1:1` с экранной лупой для далёких дисков.
- **Глубокий космос и радиоимпульс (`V`):** оверлей миссий (`JWST · L2`, `Voyager 1`, `New Horizons`) и кнопка `📡 Радиосигнал с Земли` в карточке объекта, показывающая реальное 3D-расстояние до Земли и пролёт светового импульса со скоростью света `c`.

**Управление**

| Действие | Как |
|----------|-----|
| Камера | тянуть — вращать, колесо — зум, правая кнопка — сдвиг |
| Выбрать объект / спутник | клик по нему, список слева, клавиши `0–9`, `C`, `H` или `⇧0–9` |
| Перебор соседних / обзор | стрелки `←` / `→`, `Esc` / «↺ Обзор» |
| Пауза и шаг эпохи | `Пробел` — пауза, дата / `T` — сегодня, кнопка шага (дн/с…год/с) |
| Сравнение и масштаб | `G` — линейка размеров, `R` — «Схема ↔ 1:1», `V` — миссии |
| Свечение и звук | `B` — режим bloom (`Авто / Вкл / Выкл`), `M` — Web Audio музыка |

## Публикация на GitHub Pages

Репозиторий готов к Pages без сборки: в **Settings → Pages → Build and deployment** выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`. Через минуту-две сайт появится на <https://solasfor.github.io/Opus/>.

## Технические заметки

- Аквариум (`Akvarium/Аквариум max.html`) — один самодостаточный файл на чистом WebGL 2 (собственная математика матриц/кватернионов, шейдеры, FBO-каустика и тени, без внешних библиотек и сетевых запросов).
- Двигатель: `Engine/index.html` подключает `Engine/src/main.js` (Three.js 0.160, ES-модуль и `importmap` с unpkg); спецификация V12 60° (5,5 л, 88 × 75 мм), кинематика 6 общих шеек, 4 распредвалов и 48 клапанов, цикл и термодинамика выделены в чистые модули `src/config` и `src/sim`. Тесты: `node --test "Engine/tests/*.test.js"` (Node 22.7+ или 20.19+, без зависимостей).
- Солнечная система (`SolarSystem/SolarSystem.html`) — самодостаточный файл на Three.js r128 и постобработке без сборки и без внешних шрифтов. Тесты эфемерид J2000, решателя Кеплера, перекрытия дисков, люков Кирквуда и шейдеров: `node --test "SolarSystem/tests/*.test.js"`.
- Бандлер нигде не нужен.
- Геометрия — процедурная (объединённые меши и `InstancedMesh`), текстуры и шейдерные эффекты — в рантайме.
- Звук двигателя синтезируется через WebAudio и по умолчанию выключен.
