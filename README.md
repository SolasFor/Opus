# Opus

Две интерактивные 3D-сцены на Three.js. Каждая — один самодостаточный HTML-файл: без сборки, без npm, без локальных ассетов. Вся геометрия и текстуры генерируются процедурно в рантайме, библиотеки подтягиваются с CDN (с несколькими зеркалами на случай недоступности основного).

| Демо | Файл |
| --- | --- |
| Аквариум | [`Akvarium/Aquarium.html`](Akvarium/Aquarium.html) |
| Двигатель | [`Engin/Engin.html`](Engin/Engin.html) |

## Запуск

Откройте любой из файлов в браузере — двойным щелчком или через локальный сервер:

```bash
python -m http.server 8000
```

Затем <http://localhost:8000/Akvarium/Aquarium.html>.

Нужны браузер с WebGL и доступ в интернет: Three.js, OrbitControls и GSAP загружаются с CDN (jsDelivr / unpkg / cdnjs).

## Аквариум

[`Akvarium/Aquarium.html`](Akvarium/Aquarium.html) — рифовая сцена на Three.js 0.147.

- **Стайное поведение.** Рыбы четырёх видов расходятся по отдельным стаям: сближение, выравнивание курса и расталкивание считаются по соседям. Каждый вид со своими пропорциями тела, скоростью и амплитудой взмаха хвоста.
- **Кормление.** Клик по поверхности воды или кнопка «Покормить рыб» бросает хлопья; рыбы идут к ним, хлопья тонут и расходятся.
- **Свет.** Три режима — день, закат, ночь — плавно интерполируют цвет и интенсивность всех источников, туман, экспозицию, тон воды и фона. Ночью проявляется биолюминесценция.
- **Вода и каустика.** Поверхность волнуется в вершинном шейдере; каустика запекается на процедурную текстуру Вороного и встраивается в стандартные материалы через `onBeforeCompile`, поэтому рисунок света ложится по рельефу грунта, а не висит плоско.
- **Сцена.** Процедурный рельеф песка, камни, водоросли с качанием в шейдере, кораллы, пузырьки аэратора, планктон и стеклянный аквариум с рамой и тумбой.

Управление: клик — корм, ЛКМ — вращение, колесо — масштаб, ПКМ — сдвиг. Клавиши: `F` — покормить, `1` / `2` / `3` — день / закат / ночь. Слайдеры задают количество рыб и скорость симуляции.

## Двигатель

[`Engin/Engin.html`](Engin/Engin.html) — четырёхтактный рядный четырёхцилиндровый двигатель, интерактивная разнесённая сборка. Three.js r128 + OrbitControls + GSAP.

- **Разборка.** Слайдер и кнопки Assemble / Explode разводят детали плавно; пошаговый режим (`◀ Prev` / `Next ▶`) разбирает двигатель в порядке: свечи → клапаны → головка → выпускной коллектор → блок → поршни → коленвал.
- **Анимация работы.** Кривошипно-шатунный механизм считается точно: поршни ходят по закону шатуна, шатуны разворачиваются по вектору от шейки к пальцу, распредвалы вращаются вдвое медленнее коленвала, клапаны открываются по окнам фаз газораспределения.
- **Выбор детали.** Наведение подсвечивает узел, клик наводит камеру и открывает карточку с описанием и характеристиками; есть быстрые чипы по компонентам.
- **Сцена.** Открытый картер с полупрозрачной передней стенкой и гильзами, трёхточечный студийный свет, тени, контактная «тень»-декаль и сетка на полу.

Управление: перетаскивание — орбита, колесо — масштаб, правая кнопка — панорама, клик по детали — карточка. Клавиши: `←` / `→` — шаги, `Space` — пуск/стоп анимации, `R` — сброс камеры, `Esc` — закрыть карточку.
